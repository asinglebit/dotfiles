# Code comments

Comment only where the behavior cannot be read off the code and the variable
names themselves. No comment is the default; a comment is the exception.

- Write it ELI5: plain words, as if to someone reading this code for the first
  time.
- Straight to the point. No preamble, no rationale essays, no history, no
  restating what the line already says.
- One sentence, maximum. If it needs two, rename something instead.
